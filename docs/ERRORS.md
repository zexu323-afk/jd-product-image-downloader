# 错误处理与边界

| 情况 | 本分享版行为 | 建议处理 |
|---|---|---|
| 登录页、验证码或平台限制 | 停止，不自动重试 | 用户亲自处理登录/限制后再决定是否运行 |
| 下载 HTTP 401/403/429、HTML 验证响应 | 明确阻断错误，不当作正常空图片 | 核对平台状态，不绕过 |
| 主图或详情图来源缺失 | 失败，不生成成功清单 | 检查页面模板及已登录环境 |
| 网络、长度或文件类型异常 | 下载失败，无成功清单 | 检查原因；不使用残留文件冒充完整采集 |
| 浏览器依赖或运行时不存在 | 失败，不自动安装 | 按 README 准备个人环境 |
| 同一输出会话编号已存在 | 拒绝覆盖 | 使用新会话编号 |
| 用户中止 | 退出并关闭本次上下文 | 已产生文件留在 `.local`，不自动删除 |

## 公开与邀请分享的文件边界

仅源码、文档、原创/虚构样例和离线测试进入 Git。`.local/`、虚拟环境、浏览器 profile、下载文件、数据库和日志都忽略。不要移除这些忽略规则后整目录上传。

CLI 不打印浏览器原始异常，因为其中可能含临时签名 URL；只显示受控错误码。页面可能在运行内存中使用自己的临时参数，但不写进输出清单。离线输入示例的链接为虚构示意，不含真实签名。

## 已知限制

- 目前是 Windows、单 SKU、人工登录的技术示例，无调度、自启动或多商品重试机制。
- 主图是原有 800×800 策略，不等于最高分辨率原图；没有人工核对就不能保证发现完整性。
- 只读页面检查依赖既有提示文本；详情请求发生错误时可能统一为 `DETAIL_SOURCE_UNAVAILABLE`，不会自动绕过或重试。
- 文件头检查不等于完整图像解码，也不是恶意文件扫描。
- 下载失败可能留下部分文件；清单未完成时不得作为成功结果使用。
- 原始下载器支持 JSON 输入，但分享版推荐通过 CLI 生成唯一会话编号，避免自行拼接命令。
- 本地登录态仅应由本人保管；不要把它发给仓库协作者。
